# 📮 Postman Collection - Инструкция

## 🚀 Быстрый старт

### 1. Импорт коллекции в Postman

1. Откройте Postman
2. Нажмите **Import** (левый верхний угол)
3. Выберите файл `postman_collection.json`
4. Коллекция **Auth Service API** появится в списке

### 2. Настройка переменных

Коллекция использует переменные для хранения данных между запросами:

| Переменная | Значение по умолчанию | Описание |
|------------|----------------------|----------|
| `baseUrl` | `http://localhost:3000` | URL сервера |
| `email` | `test@example.com` | Email для тестов |
| `password` | `password123` | Пароль для тестов |
| `verificationCode` | (пусто) | Код из email |
| `resetCode` | (пусто) | Код сброса пароля |
| `authToken` | (пусто) | Автоматически |
| `userId` | (пусто) | Автоматически |

**Изменить переменные:**
1. Нажмите на коллекцию **Auth Service API**
2. Вкладка **Variables**
3. Измените `email` и `password` на свои

## 📋 Порядок выполнения тестов

### Сценарий 1: Полная регистрация нового пользователя

```
1. Health Check          → Проверка сервера
2. Регистрация           → Создание аккаунта
   ⚠️ Проверьте email и скопируйте код!
3. Подтверждение email   → Вставьте код в переменную verificationCode
4. Проверка авторизации  → Убедитесь, что залогинены
5. Получить профиль      → Просмотр данных
6. Выход                 → Выход из системы
```

### Сценарий 2: Логин существующего пользователя

```
1. Логин                 → Вход в систему
2. Проверка авторизации  → Проверка токена
3. Получить профиль      → Данные пользователя
4. Выход                 → Выход
```

### Сценарий 3: Восстановление пароля

```
1. Забыли пароль         → Запрос кода
   ⚠️ Проверьте email и скопируйте код!
2. Сброс пароля          → Вставьте код в переменную resetCode
3. Логин                 → Вход с новым паролем
```

### Сценарий 4: Админские функции

```
1. [ADMIN] Логин админа              → Вход под админом
2. [ADMIN] Получить всех пользователей → Список пользователей
3. [ADMIN] Повысить до premium        → Повышение статуса
4. [PREMIUM] Получить премиум контент → Проверка доступа
```

### Сценарий 5: Внутренние API (для микросервисов)

```
1. Логин                           → Получить токен
2. [INTERNAL] Валидация токена     → Проверка токена
3. [INTERNAL] Проверка пользователя → Проверка email
```

## ⚙️ Важные настройки Postman

### Включить автоматическую обработку cookies:

1. **Settings** (⚙️ справа вверху)
2. **General** → **Cookies**
3. Включите: **Automatically follow redirects**
4. Включите: **Send cookies**

Это критично! Без этого токены не будут сохраняться.

## 🔍 Автоматические тесты

Каждый запрос содержит автоматические проверки:

### Пример: Регистрация
```javascript
✅ Status code is 200
✅ Response has success field
⚠️ Проверьте email для получения кода!
```

### Пример: Логин
```javascript
✅ Status code is 200
✅ Login successful
✅ Token saved automatically
```

Результаты тестов видны в **Test Results** после выполнения запроса.

## 📝 Как использовать коды из email

### Шаг 1: Выполните запрос "Регистрация"
Вы получите email с кодом вида: `123456`

### Шаг 2: Скопируйте код

### Шаг 3: Вставьте в переменную
1. Нажмите на коллекцию **Auth Service API**
2. Вкладка **Variables**
3. Найдите `verificationCode`
4. Вставьте код в столбец **CURRENT VALUE**
5. Нажмите **Save** (Ctrl+S)

### Шаг 4: Выполните "Подтверждение email"

## 🐛 Решение проблем

### Проблема: "No token provided"
**Решение:** 
- Убедитесь, что cookies включены в настройках Postman
- Выполните логин заново
- Проверьте, что в Cookies есть `authToken`

### Проблема: "Token expired"
**Решение:**
- Токен живёт 7 дней
- Выполните логин заново

### Проблема: "Device not trusted"
**Решение:**
- Fingerprint привязан к User-Agent
- Не меняйте User-Agent между запросами
- Выполните логин заново

### Проблема: "Invalid verification code"
**Решение:**
- Код действителен 15 минут
- Проверьте, что скопировали правильный код
- Используйте "Повторная отправка кода" (макс 3 попытки)

### Проблема: "Email already exists"
**Решение:**
- Измените переменную `email` на другой адрес
- Или используйте "Логин" вместо "Регистрация"

## 🎓 Полезные советы

1. **Используйте Runner** для автоматического прогона всех тестов:
   - Нажмите на коллекцию → **Run**
   - Выберите нужные запросы
   - Нажмите **Run Auth Service API**

2. **Сохраняйте окружения** для разных серверов:
   - Dev: `http://localhost:3000`
   - Staging: `https://staging-api.example.com`
   - Production: `https://api.example.com`

3. **Экспортируйте результаты** тестов:
   - После выполнения Runner
   - Нажмите **Export Results**
   - Сохраните JSON для отчётов

4. **Мониторинг API**:
   - Postman Monitor может запускать коллекцию по расписанию
   - Полезно для проверки доступности API
